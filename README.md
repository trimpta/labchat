# LabChat

Zero-dependency terminal chat for local networks.

## Requirements

Python 3.9+

## Run

python labchat.py

## Windows

python labchat.py

## Linux

python3 labchat.py

## Features

- LAN discovery
- Automatic subnet scanning
- Direct IP connections
- Configurable port
- Terminal UI
- No external dependencies

## Commands

/help
/users
/discover
/scan
/connect <ip[:port]>
/disconnect
/name
/status
/server
/port
/clear
/quit

## Networking

LabChat uses TCP for chat communication and UDP for LAN discovery.
